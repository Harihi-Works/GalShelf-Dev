## GalShelf 0.2.4

### 应用更新

- 新版本改由 GitHub Releases 发布：客户端从本仓库读取签名的更新清单，并在这里下载安装包。
- 安装前会核对更新清单的签名，以及安装包的大小和 SHA-256。任何一项不一致都不会安装。
- 正在记录游玩时间时不会安装或重启，也不会关闭游戏。安装失败时会自动恢复原来的程序文件。
- 更新只替换程序文件。书架、设置、游玩记录、订阅与通知保存在 `%LOCALAPPDATA%\GalShelf`，不受影响。

### 资源管理器集成

- 「设置 · 系统集成」新增「启用资源管理器集成」开关。
- 开启后，右键 `.exe` 可以选择「添加到 GalShelf」，右键文件夹可以选择「用 GalShelf 扫描游戏」。
- 只写入当前用户的注册表，不需要管理员权限；关闭开关就会移除。在 Windows 11 中，这两项位于「显示更多选项」。

### 安装

- 解压 `GalShelf-Windows-0.2.4.zip`，把其中的文件复制到原来的 GalShelf 文件夹（例如 `C:\GalShelf`），然后启动 `GalShelf.exe`。
- 已安装 0.2.3 或更早版本的，需要手动更新到这一版；之后的版本可以在客户端内自动更新。
- 安装包的 SHA-256 见 `GalShelf-Windows-0.2.4.zip.sha256` 与 `SHA256SUMS.txt`。
