## GalShelf 0.2.5

### 游戏菜单与截图

- 新增游戏菜单：在游戏里按 `Ctrl+Alt+G`（可在设置中更改或关闭），菜单会显示在游戏窗口旁，集中提供截图、窗口透明度与置顶、画面缩放（Magpie）和一键恢复。菜单只作用于正在计时的这部作品自己的窗口。
- 截图后会冻结画面并在游戏窗口上打开编辑器，游戏不会暂停。可以裁剪、矩形或涂抹打码、使用打码建议，所有操作都可以撤销和重做；完成后保存并复制到剪贴板。
- 编辑器中可以使用本机超分（2× / 4×），也可以识别画面中的台词（本机文字识别，结果需要确认后才会作为台词使用），并直接制作分享卡。
- 新增截图设置：截图范围（整个窗口、按作品记住的区域或每次手动选择）、是否立即保存、自动复制、自动超分、打码建议与自动打码、截图后识别台词、保存后是否制作分享卡。
- 可以为每部作品保存窗口透明度与置顶设置，并在每次开始计时时自动应用；结束计时或关闭 GalShelf 时窗口会恢复原样。

### 手柄映射键盘

- 可以把手柄按键映射成游戏中的键盘按键，支持全局配置与按作品的单独配置、摇杆与扳机阈值。默认关闭；GalShelf 自己在前台时不会发送按键，切换窗口、结束游戏或断开手柄时会松开所有按键。

### 书架与设置

- 作品详情中的操作整理为常用按钮和「更多操作」菜单。
- 新增设置搜索，支持中文与英文关键词，直接定位到对应设置项，搜索不会改变任何设置。
- 大屏模式现在会切换为适合电视和手柄浏览的布局，并记住选择。
- 拖入文件夹或游戏程序会进入导入确认流程；拖到作品卡片上时可以选择更新该作品的路径或作为新作品导入。
- 浅色主题下计时条与书架次要文字的对比度提高。

### 月历与订阅

- 月历只加载看过的月份，返回已看过的月份时立即显示；离开月历再回来会保留月份、日期与打开的作品。
- 在作品详情中可以直接切换到当天的上一部 / 下一部作品，以及前一天 / 后一天（`Alt` + 方向键）。
- 「愿望单」改为「订阅」：详情中直接显示游戏资源与补丁的状态（可用 / 暂无 / 未知），并可分别订阅。订阅的内容变为可用时，通知中心会提醒一次。原有愿望单会自动转为订阅。
- 来自书架上已有会社（同一会社、同一品牌、姐妹品牌或同一品牌家族）的新作带金色标记，悬停可查看原因。
- 书架上已有灰色目录卡片的作品，加入书架时会直接成为你的记录，不会重复添加。只登记到月份的发售日按原精度保存。

### 账号

- GalShelf 账号密码与 NextMoe 登录现在进入同一个账号：已登录时可以绑定 NextMoe，用 NextMoe 登录的账号也可以设置账号名和密码。第一次用 NextMoe 登录时会询问是创建新账号还是绑定已有账号，不会再自动创建另一个账号。
- 如果同一个人已有两个账号，可以在确认两边的书架与记录后把它们合并；合并前会显示预览，不安全的情况会被拒绝。也可以解除 NextMoe 绑定（需要账号设置了密码）。
- 客户端默认连接 `galshelf.com`。以前在客户端中登录过的，更新后请重新登录一次；本机书架、设置和游玩记录不受影响。

### 分享卡

- 新增渚（Nagisa）与 Sora 的可编辑模板和配图，新增角色贴纸、心情团子贴纸与更多素材。

### 试验功能

- 选项记录：为某部作品开启后，GalShelf 会在游戏位于前台时在本机识别选项画面，整理成选择时间线，可以确认或更正。默认关闭，只保存选项文字，不保存截图，不上传。

### 安装

- 已安装 0.2.4 的客户端会在应用内收到更新；也可以解压 `GalShelf-Windows-0.2.5.zip`，把其中的文件复制到原来的 GalShelf 文件夹（例如 `C:\GalShelf`），然后启动 `GalShelf.exe`。
- 更新只替换程序文件，书架、设置、截图、游玩记录、订阅与通知保存在 `%LOCALAPPDATA%\GalShelf`，不受影响。
- 安装包的 SHA-256 见 `GalShelf-Windows-0.2.5.zip.sha256` 与 `SHA256SUMS.txt`。
